**Status:** cópia de referência. O portal oficial é [`apps/web`](../apps/web/README.md).

## Histórico

Portal inicial com Next.js App Router, TypeScript e Blockforge Design System. Protótipo de wallet Devnet (challenge local; sem txs).

```bash
pnpm install
pnpm dev
```

Para desenvolvimento ativo use:

```bash
pnpm dev:web   # na raiz do monorepo → apps/web
```
