# MutterGames Web

Portal inicial do ecossistema MutterGames, construído com Next.js App Router, TypeScript e o Blockforge Design System.

## Executar

```bash
pnpm install
pnpm dev
```

Abra `http://localhost:3000`.

## Primeira entrega

- Home pública responsiva.
- Páginas de jogos, ecossistema e portal do jogador.
- Design system Blockforge em CSS.
- Protótipo de conexão de wallet Solana Devnet.
- Endpoint local para geração de challenge.

O protótipo não envia transações nem movimenta fundos. A verificação criptográfica server-side e Wallet Standard completo entram na próxima etapa.
