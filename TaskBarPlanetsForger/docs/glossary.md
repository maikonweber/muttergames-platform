# Glossário

- **Idle game:** jogo cuja simulação continua com pouca interação.
- **Tick:** passo determinístico de atualização da simulação.
- **Progresso offline:** ganhos calculados entre último save e retorno.
- **Prestígio:** reinicialização voluntária em troca de bônus permanente.
- **Fonte / sumidouro:** origem / consumo de recurso.
- **Essência Cósmica:** moeda permanente de prestígio.
- **Seed:** valor que torna geração aleatória reproduzível.
- **Save / migração:** estado persistido / transformação segura entre versões.
- **Janela compacta / expandida:** faixa discreta / painel de gerenciamento detalhado.
