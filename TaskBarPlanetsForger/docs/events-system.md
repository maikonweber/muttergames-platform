# Sistema de eventos

Eventos possuem `id`, categoria, seed, pré-condições, probabilidade, duração, escolhas e efeitos reversíveis quando possível. O gerador usa seed persistida para testes determinísticos e aplica recarga por categoria.

| Categoria | Exemplos |
|---|---|
| Positivo | chuva de meteoros, aurora energética, descoberta mineral, salto científico, cooperação interestelar |
| Negativo | impacto, erupção, era glacial, aquecimento, praga, extinção, guerra, rebelião, colapso ambiental |
| Neutro/decisão | visita alienígena, IA emergente, sonda perdida, eclipse, anomalia gravitacional |
| Raro | planeta vivo, civilização máquina, supernova, formação de buraco negro, dimensão alternativa |

São 20 exemplos. Eventos incompatíveis não concorrem, eventos críticos pedem confirmação no modo expandido e notificações podem ser desativadas.
