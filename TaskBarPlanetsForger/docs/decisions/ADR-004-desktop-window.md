# ADR-004 — Janela desktop

**Status:** [PROPOSTA]. Sempre no topo é opcional e reversível. A janela respeita monitor, DPI e escolha do usuário; não deve depender de detectar perfeitamente a barra de tarefas. Bandeja, atalho de ocultar e redução em tela cheia mitigam interrupções. Validar limitações por Windows e gerenciadores de múltiplos monitores no protótipo.
