# TaskBar Planets Forger

Jogo idle desktop **Windows-first** (Godot 4.7): forje planetas na barra de tarefas, terraform e evolua civilizações offline.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| [`docs/`](docs/README.md) | Visão, GDD, SRS, arquitetura, ADRs, economia, roadmap |
| [`task-bar-planet-forger/`](task-bar-planet-forger/README.md) | Protótipo Godot (MVP jogável) |
| `docs/procedural-sprite-tool.md` | Seed Lab (sprites determinísticos) |

## Começar

1. Leia [`docs/README.md`](docs/README.md).
2. Abra `task-bar-planet-forger/project.godot` no Godot 4.7+.
3. Para o laboratório de seeds: execute `scenes/seed_lab.tscn` (F6).
