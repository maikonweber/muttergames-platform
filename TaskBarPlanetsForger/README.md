# TaskBar Planets Forger

Pasta reservada para a documentação, decisões de produto e futuros artefatos do projeto **Taskbar Planets**.

## Estrutura planejada

- `docs/`: especificação funcional e técnica do jogo;
- `docs/decisions/`: Architecture Decision Records (ADRs);
- `assets/`: referências visuais e materiais de apoio;
- `src/`: código do jogo, quando a fase de implementação for autorizada.

O próximo passo é gerar os documentos definidos no prompt de especificação dentro de `docs/`.
