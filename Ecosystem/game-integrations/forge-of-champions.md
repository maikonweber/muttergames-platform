# Integração — Forge of Champions

## Status

**Conceito.** Sem cliente de jogo, sem eventos econômicos, sem catálogo de assets no launcher.

## Quando ativar esta integração

1. GDD em Markdown aprovado (`ForgeOfChampions/docs/`).  
2. Protótipo jogável com `game_id` registrado na API.  
3. Decisão explícita de quais cosméticos (não poder) entram on-chain.

## Mapeamento provisório

| Sistema | Integração futura |
|---|---|
| Partidas / ranked | Off-chain autoritativo; rewards só pós-antifraude |
| Cartas base | Conteúdo de gameplay — não tokenizar poder |
| Skins / backs / emotes | Cosméticos elegíveis |
| Soft currency | Off-chain por jogo |
