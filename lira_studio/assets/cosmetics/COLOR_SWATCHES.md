# Amostras de cor

Os seis cards em `swatches/` foram fatiados do atlas `atlas/cosmetic_color_swatches_v1.png`. Cada card tem 512 × 512 px e fundo opaco, portanto serve como thumbnail de catálogo — não como overlay de maquiagem.

| ID sugerido | Arquivo | Categoria | Cor de referência |
| --- | --- | --- | --- |
| `lip_ruby` | `swatches/swatch_ruby_lip_card_v1.png` | Batom | Rubi. |
| `lip_rose` | `swatches/swatch_rose_lip_card_v1.png` | Batom | Rosa suave. |
| `lip_plum` | `swatches/swatch_plum_lip_card_v1.png` | Batom | Ameixa. |
| `shadow_champagne` | `swatches/swatch_champagne_shadow_card_v1.png` | Sombra | Champanhe. |
| `shadow_copper` | `swatches/swatch_copper_shadow_card_v1.png` | Sombra | Cobre. |
| `shadow_violet` | `swatches/swatch_violet_shadow_card_v1.png` | Sombra | Violeta. |

O ID da seleção deve apontar também para parâmetros de cor/intensidade ou para overlays por modelo. A miniatura jamais define sozinha o tom aplicado.
