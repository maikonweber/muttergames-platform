# Ferramentas cosméticas da UI

Os seis sprites foram extraídos de `atlas/ui_cosmetic_tools_atlas_v1.png` e estão em `cosmetic_tools/`. Cada arquivo tem 512 × 512 px, canal alfa preservado e é destinado ao menu de categorias e ao HUD de aplicação.

| ID sugerido | Arquivo | Ação no jogo |
| --- | --- | --- |
| `tool_lipstick` | `cosmetic_tools/tool_lipstick_card_v1.png` | Abre a categoria de batom. |
| `tool_brush` | `cosmetic_tools/tool_brush_card_v1.png` | Representa pincel/aplicação por toque. |
| `tool_eyeshadow` | `cosmetic_tools/tool_eyeshadow_palette_card_v1.png` | Abre a categoria de sombra. |
| `tool_eyeliner` | `cosmetic_tools/tool_eyeliner_card_v1.png` | Abre a categoria de delineador. |
| `tool_mascara` | `cosmetic_tools/tool_mascara_card_v1.png` | Abre a categoria de máscara de cílios. |
| `tool_sponge` | `cosmetic_tools/tool_sponge_card_v1.png` | Abre base, blush ou preparação. |

Use 96–128 px visuais no HUD e área de toque mínima de 48 dp. A ordem dos arquivos segue a grade original: duas colunas por três linhas.
